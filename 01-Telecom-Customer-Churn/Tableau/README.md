# 📊 Telecom Customer Churn Analysis Dashboard (Tableau)

## 📌 Project Overview

This project presents an interactive **Telecom Customer Churn Analysis Dashboard** built using **Tableau Desktop**. The dashboard helps analyze customer churn patterns by exploring customer demographics, contracts, payment methods, internet services, tenure, and other key business dimensions.

The objective of this project is to identify factors influencing customer churn and provide business insights that can help improve customer retention strategies.

---

## 🎯 Project Objectives

- Analyze customer churn behavior.
- Monitor key business KPIs.
- Identify high-risk customer segments.
- Compare churn across different customer attributes.
- Build an interactive dashboard for business users.

---

## 📈 Key Performance Indicators (KPIs)

The dashboard displays the following KPIs:

- 👥 Total Customers
- ⏳ Average Customer Tenure
- 💰 Average Monthly Charges
- 📉 Churn Rate
- ✅ Active Customers
- ❌ Churned Customers

- Contract Type

- Internet Service

All visualizations and KPIs update automatically based on the selected filters.

---

## 📌 Key Insights

Some business insights that can be derived from the dashboard include:

- Month-to-month contract customers have the highest churn rate.
- Customers using Fiber Optic internet services show higher churn compared to DSL customers.
- Customers without Tech Support are more likely to churn.
- Customers without Online Security exhibit higher churn.
- Higher monthly charges are associated with increased churn.
- Long-tenure customers are less likely to churn.
